# Python QR Code Generator 📱

This is a simple QR code generator I made using Python. It takes text or a URL from the user and creates a QR code as a PNG image.

## What It Does

* Takes text or a URL from the user
* Lets the user choose the file name
* Creates a QR code
* Saves the QR code as a PNG image

## What I Used

* Python
* `qrcode` library
* User input
* Conditional statements
* String methods
* File saving

## How to Run

First, install the required library:

```bash
pip install -r requirements.txt
```

Then run:

```bash
python qr_generator.py
```

## Example

```text
Enter your text or URL: https://github.com
Enter your file name: github

QR code saved as github.png
```

The generated QR code will be saved in the same folder as the Python file.
